# Գրիչ — app

Installable web app (PWA) for «Գրիչ»: instant price calculator, 3-step order request, "My orders" with deadlines, FAQ. Armenian / Russian / English. Works offline.

- Prices: `TYPES` in `index.html`. Contacts: `CONTACT` in `index.html`.
- After changing any file, bump `VERSION` in `sw.js` so installed phones get the update.
